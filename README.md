# Goodnight Inn: where should the $60M go?

Entry for the **Power BI Dataviz World Championships ATL 2027, Round 1 (Investment Challenge)**, built on the Pillow & Key Group data. Pillow & Key Group is fictional.

**Live report:** (https://app.powerbi.com/view?r=eyJrIjoiMGE2YmVjOTgtODE4Ni00MmM1LTg5YTItMDRkNjIyOGFhM2NhIiwidCI6IjU4ZTkzNGIyLTE4ZGUtNDBjNy04NzhjLThlZGI3YzE5Y2RhMiJ9)

## The answer

Spend **$13.65M** (23% of the $60M budget) on four projects and hold the other **$46.35M** to re-test the bigger projects with 2027 results.

| | |
|---|---|
| Projects | Direct booking app, revenue management, self check-in, breakfast upgrade |
| Expected value by 2032 | +$3.7M (Low -$7.0M, High +$14.6M) |
| Extra profit a year | about $4.4M |
| Cash pays back | Mar 2031 |

## The two pages

1. **Brand Review:** online travel agencies bring 50% of room revenue but take 80% of distribution cost. Four lenses (Channels, Margin, Growth, Guests).
2. **Investment Strategy:** A budget dial shows the price of ambition. Every extra $10M we insist on spending costs about $6.5M of value by 2032.

## How it was built

- All 456 possible project combinations tested under Low, Expected and High scenarios.
- Values discounted to 2026 at 8%, with inflation. In 2025 dollars with no inflation, the plan is still worth +$2.0M.
- Custom SVG visuals written in DAX, bookmark-driven cover, hidden tooltip pages.
- Accessibility: alt text on every visual, set tab order, colour contrast checked.
